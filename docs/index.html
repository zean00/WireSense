the signature idea

One embedding. Many heads. Zero extra inference per level.

Every node of the tree is a head-projected class centroid over the same slot-6 embedding of the raw utterance — the think subtree reuses the root's vector, so a two-level routing decision costs one encoder pass. Try routing real utterances:

root held-out 56/62 think subtree 24/26 tree vs flat e2e 47/56 vs 35/56 confidence gating — rejected (miscalibrated)
the load-bearing discipline

Two-zone context: freeze the prefix, stream the suffix.

A byte-stable prefix carries the conversation; only the volatile suffix ever changes. Byte-stability is the point: a prefix that never rewrites is cacheable, and the rules below — mode directives, the memory digest — exist to protect it.

frozen prefix — byte-stablesystem block + history + vision context · byte-stable across turns · never rewritten mid-session
volatile suffixstreaming utterance, LCP-trimmed · mode directives ride the turn
rule 1

Mode directives (deep, tool, memory…) ride the current user turn — never the system block — so switching behavior never invalidates the cache.

rule 2

The memory recall digest rides the answer turn only — never the system block, never planner history (the camera-line and MS-20 precedents).

rule 3

History stays raw ASR text. Fragments are rewritten into a scratch slot before routing; the prefix is untouched.

what it can do

Capabilities, each one measured.

No demo-ware: every capability below ships with a registered acceptance bar and a result on the ledger.

Real-time conversation

Streaming partials, visible live <think> reasoning (rendered, never spoken), barge-in mid-sentence, per-turn latency chips, live dual waveform.

Tools & persistent memory

Timers with client toasts, reminders that re-arm across restarts, notes — and memory capture: "remember this…" stores, a fresh session still recalls, "forget…" removes.

MCP tool ecosystem

28 live tools over stdio + remote Streamable-HTTP, {server}__{tool} namespacing, schema validation, self-healing connections, and a spoken confirm before anything risky.

Vision & perception

Camera Q&A act-then-decide (frame per vision turn), opt-in face recognition storing embeddings only, and an open-vocabulary detector sidecar for "what's on the table".

Research agent (IR)

"Research how X works" spawns a background multi-fetch agent — depth-3 retrieval with query reformulation — that answers out-of-turn with evidence, guarded by budget and submit checks.

Browser agent

Real GUI automation for local pages and forms — and when it can't find the answer, it ends stuck and says so. A done-gate rejects wrong answers instead of celebrating them.

Deep-think escalation

"Think hard about…" escalates to a bigger external model through pluggable dialects (openai-chat / responses / anthropic) — off by default, on your terms, streaming the reasoning back. Agentic history is clipped to the provider's real serving window — detected from /props, never the training bound.

Honest degradation

No live weather? It says so. Tool plan fails twice? Honest brief answer instead of a hallucinated tool result. Refusals, parked and stuck are first-class outcomes.

one execution discipline

The ledger: register first, measure, admit when wrong.

Protocols are committed before data exists; evals are frozen; results are append-only — including the retractions. Twelve protocol documents make up the project's decision record; these are some entries.

measured, pre-MCP

Synth-pool tool selectionMS-4

Gate selection (k=5 clustering over per-tool synth utterances) reaches 70.1% at 121 tools — and the option tax is measured: merely offering a search escape costs ~4 points on turns that never use it.

registered → rejected

MCP search toolMS-15

Both search variants rejected on measurement — the planner's short queries surfaced targets 51% vs 87.8% for embedding the utterance itself. The gate is the search. No search tool shipped.

deployment discipline

Per-server deployment gatesMS-16

A server is enabled only after clearing its frozen eval: pos ≥ 0.60, neg ≥ 20/24. Recipe B9 (self-contained utterances) fixed the eval, not the model — and the autopsy was published.

planner hygiene

History bleeds, measuredMS-20

Full history made the tool planner hallucinate: a weather question fired the time tool with a fabricated readback. Battery: last-2 history 12/12, adopted; full history and history-free both fail.

2026-10-07

The universe correction2 retractions

The memory feature's gate re-runs exposed a ground mismatch: the registered clearance had been measured with a demo server connected (41 tools) while production runs 28. The "manifest costs 9 points" claim was retracted, the version-flap theory retracted, and the correction committed the same day.

2026-10-07

Flat-28, adopted by rulepre-registered

The never-measured 21–40-tool band got its first point: flat beats the gate at 28 (fs 0.6094 · git 0.6875 · time 0.7500). Decision rule committed before data; one-case margin disclosed; policy amended — gates run the exact enabled set.

2026-10-07

The prefill retractionretraction

This page credited "incremental prefill" as a latency stage. It isn't shipped: entry V measured partial-warming and retired it (warm/cold prompt-time ratio 1.0–1.08), and a fresh probe re-confirmed on the production path — first token ~75 ms, ~95% of it the one commit-time prefill, the slot cache serving 0 of 120 commits. Commit-only stands.

Regression is a capabilitysuite

A 27-scenario suite drives the full turn pipeline over real models and real servers with a fake websocket — 0/24 on its first run, green on every run since, and it has caught four real bugs.

design principles

Four rules that everything else obeys.

01

GPU for the LLM only

The 8 GB budget belongs to the 4B model. ASR, TTS, detection and faces run as CPU sidecars — latency by design, not afterthought.

02

Two-zone context

Frozen prefix, byte-stable across turns; volatile suffix trimmed and delta-decoded. Prefix discipline is load-bearing.

03

The decide layer is learned, not timers

State-head readouts over the frozen encoder decide endpointing, routing, and eager response — replacing silence timeouts everywhere.

04

One execution discipline

Experiments get pre-registered protocols; components get validation harnesses. Results are append-only, retractions included.
